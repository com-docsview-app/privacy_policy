# ViewDocs privacy policy

Last updated: <17 Nov 2026>

ViewDocs is an app for reading documents on your device. It does not collect, store or share personal information.

**What the app does with your files.** When you open a file, ViewDocs reads it on your device and shows it. The file is not
uploaded, copied to any server, edited or saved back. Closing the file releases it from memory.

**What the app does not do.** No account or sign-in. No advertising. No analytics, crash reporting or tracking. No data is sent to
the developer or to third parties.

**What stays on your device.** The app remembers your viewing settings (theme, page layout) and a list of recently opened files so
you can open them again. This list and these settings never leave your device and can be cleared by clearing the app's storage or
uninstalling the app. Document text, file contents and passwords are never written to logs or settings; a password you type for
a protected file is kept in memory only until the file is open.

**Links.** If a document contains a web link, ViewDocs asks before opening it and opens it in your browser. The website you visit
has its own privacy policy. The app never loads anything a document references on its own and does not run macros or embedded code.

**Children.** The app is not directed at children and collects no data from anyone.
